## # Modern JavaScript Mastery
This repository contains my journey through JavaScript, moving from basic logic to advanced asynchronous programming and DOM manipulation.

###  Core Concepts Explored
*   **The Basics:** ES6+ Syntax, Let/Const vs Var, and Template Literals.
*   **Functions:** Arrow Functions, Callback Functions, and Higher-Order Functions (`map`, `filter`, `reduce`).
*   **The DOM:** Selecting elements, Event Listeners, and dynamically updating the UI.
*   **Asynchronous JS:** Promises, **Async/Await**, and fetching data from APIs.
*   **Object-Oriented JS:** Prototypes, Classes, and the `this` keyword.



---

###  Mini-Projects & Labs
*   **Weather Dashboard:** Using the `fetch` API to get real-time weather data.
*   **Task Tracker:** A CRUD application using **Local Storage** to persist data.
*   **Interactive UI Components:** Modals, Image Sliders, and Form Validators.
